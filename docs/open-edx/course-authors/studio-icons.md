Use this quick reference when building a course in Open edX Studio. The icons identify the main levels of the course structure and the components that can be added to a unit.

## Course structure icons

### Section

![Section icon in Open edX Studio](/img/open-edx/studio-icons/section.png)

A **section** is a broad course chapter or module. Use sections to organize major topics, weeks, or stages of a course.

### Subsection

![Subsection icon in Open edX Studio](/img/open-edx/studio-icons/subsection.png)

A **subsection** is a topic or sequential inside a section. It groups related units into a focused learning sequence.

### Unit

![Unit icon in Open edX Studio](/img/open-edx/studio-icons/unit.png)

A **unit** is an individual page inside a subsection. Add the actual learning components to a unit.

### Total elements

![Total elements icon in Open edX Studio](/img/open-edx/studio-icons/total-elements.png)

**Total elements** represents the complete set of elements inside a unit. Use it when reviewing the content blocks that make up a unit.

## Components

### Text component

![Text component icon in Open edX Studio](/img/open-edx/studio-icons/text-component.png)

Use a **Text component** for formatted text, headings, links, images, and other written learning material.

### Document

![Document icon in Open edX Studio](/img/open-edx/studio-icons/document.png)

Use **Document** for a downloadable document or other file resource that learners need to open or save.

### Video component

![Video component icon in Open edX Studio](/img/open-edx/studio-icons/video-component.png)

Use a **Video component** for video lectures or other video-based course content.

### Open Response Assessment

![Open Response Assessment icon in Open edX Studio](/img/open-edx/studio-icons/open-response-assessment.png)

An **Open Response Assessment** lets learners submit open-ended work for review by peers, staff, or another configured assessment workflow.

### Questions

![Questions icon in Open edX Studio](/img/open-edx/studio-icons/questions.png)

Use **Questions** for problem components and other questions that assess learner understanding.

## Course structure at a glance

The course hierarchy is:

**Section → Subsection → Unit → Components**

Components such as text, documents, videos, and questions are added inside units. See [Add course content](add-content.md) for step-by-step instructions.
